How it works

  1. Select a .dat video file using the drop zone or the Choose button. The frontend validates the extension and size before upload.
  2. Upload — the file is streamed to the server in chunks and saved to a unique per-job directory.
  3. Convert — FFmpeg inspects the media, then produces a real MP4 container. Progress is reported live when measurable.
  4. Download your .mp4 file. Temporary files are cleaned up automatically after a short TTL or when you click Start Again.

Limitations & honesty

  • The application is configured to accept files up to 2.00 GB (2,147,483,648 bytes). This is the application-level limit.
  • Whether a 2 GB file can actually complete depends on the hosting provider's disk space, RAM, CPU, request timeout, and whether the web service stays awake. Render's free tier may not reliably complete very large conversions.
  • Render's free web services have limited RAM (512 MB), an ephemeral filesystem, a request timeout, and may sleep after inactivity. Long conversions or large downloads can be interrupted.
  • No file is permanently stored. All temporary files are deleted after a short TTL or after you click Start Again.
  • Conversion progress is real, parsed from FFmpeg's machine-readable progress output. If the source duration cannot be determined, an indeterminate indicator is shown instead of a fake percentage.
